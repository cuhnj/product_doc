## 4. Décisions de convention de la traduction

1. **Contrôleur** comme désignation uniforme de "the controller" ; le nom complet du produit est **Contrôleur numérique de moteur asynchrone triphasé SDMC30-S** (cohérent avec le titre du manuel).
2. **Moteur asynchrone triphasé** comme version française de "three-phase asynchronous motor" ; **marche avant** / **marche arrière** pour "forward/reverse running" et "forward/reverse rotation".
3. **Fréquence de consigne** pour "Set Frequency" ; **démarrage progressif / temps de démarrage progressif** pour "Soft Start/Soft Start Time" ; **temps d'arrêt progressif** pour "Soft Closing Time" ; **freinage DC** pour "DC Braking" ; **arrêt d'urgence** pour "Emergency Stop".
4. **Capteur photoélectrique intelligent** pour "Intelligent Photoelectric Sensor" ; **capteur de commutation** pour "Switch Sensor" ; **photosenseur** conservé comme désignation du port B.
5. **Retard d'activation/de désactivation** pour "On/Off Delay" ("retard d'activation" = On Delay).
6. Types d'arrêt d'urgence : **Sto** (Arrêt de couple sécurisé), **Sbc** (Commande de frein de sécurité), **SS1** (Arrêt de sécurité de catégorie 1).
7. Relations logiques et valeurs d'affichage : les valeurs de l'appareil `And, or, Xor, rS`, `nPn, PnP`, `dLy, HLd`, `on, oFF`, `run, stp, FoL`, `Abc, Acb, A.b.c., A.c.b.` et `Ut1, Ut0` sont conservées telles quelles comme indications de l'afficheur ; `push-pull` est maintenu comme désignation du mode de sortie.
8. Boutons et indicateurs : les symboles ⊕, ⊖, ▲, ▼, ⏻ et ⚙ sont conservés sans modification ; les libellés des indicateurs (marche avant, marche arrière, marche, arrêt, défaut) sont traduits conformément au tableau du chapitre 1.2.
9. Les symboles de paramètres (F, F1, F2, FA, A1, A2, AA, Fr, Eq, Sq, t, d, y, b, h, n, o, r, u, Pn, rc, cb, oL, rL, Ph, PS, P, J, L, rA, JC, LC, JE, LE, JG, LG, JJ, LL, S1, S2, Ed, td, Ad, Jd, Ld, Fd, Sd, rd, EP, 2P, AP, JP, LP, FP, SP, rP, A, LEd, C, E, qP, AC, dU, PU, nU, AU, bU, tU, EU, SA, Sb, SU, FU, uc, uq) restent inchangés, car ce sont des indications de l'appareil ; les codes d'erreur Er01~Er15 restent également inchangés.
10. Les indications de sécurité suivent la maquette : ⚠ Danger → **⚠ Danger** ; ⚠ Warn → **⚠ Avertissement** ; ⚠ Careful → **⚠ Attention** ; Notice → **Avis** ; ❗ Essential → **❗ Obligatoire** (et dans le corps, **！Obligatoire** avec le point d'exclamation pleine chasse, identique à la maquette).
