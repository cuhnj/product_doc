## 4. Décisions de convention de la traduction

1. **Contrôleur** comme dénomination continue de « the controller » ; le nom complet du produit est « Contrôleur intelligent à fréquence variable pour alimentateur vibrant » (cohérent avec le titre français de ce manuel).
2. **Alimentateur vibrant** pour « Vibratory Feeder » ; **vibrateur** pour « vibrator » ; **capteur de vibration** pour « Vibration Sensor ».
3. **Commande marche/arrêt** pour « ON/OFF Control » ; le nom de la touche « ON/OFF » est conservé tel quel (« bouton ON/OFF ») ; de même pour les touches FUNC, Vol+, Vol-, ▲, ▼.
4. **Retard d'enclenchement / retard de déclenchement** pour « On Delay / Off Delay » (paramètres J/L des ports C ainsi que Jd/Ld du port D), conformément au lot français de la série.
5. **Temps de démarrage progressif** pour « Soft Startup Time » (paramètre t).
6. **Relation logique** pour « Logical Relation » ; **Opération logique** pour « Logic Operation » (6.3.3 Opération logique de la sortie principale, 6.5.3 Opération logique de la sortie de contrôle).
7. **Contrôleur maître / contrôleur esclave** pour « Master/Slave Controller » (configuration Sync) ; **effet de battement** pour « beat effect » ; **mode Sync** pour « Sync Mode » (Sync conservé).
8. **Capteur photoélectrique de type barrage** pour « Photoelectric Couple Sensor » ; **capteur photoélectrique à réflexion** pour « Reflective Photoelectric Sensor » ; **capteur à fibre optique de type barrage** pour « Fiber Optic Couple Sensor » (précédent allemand réinterprété : la version de référence traduit par « barrage »/« réflexion », l'anglais « couple » étant compris comme transmission en vis-à-vis).
9. **PLC** conservé tel quel (non traduit en « automate programmable »), conformément aux occurrences du lot ; de même NPN/PNP/Uto/nPn/PnP, Modbus ASCII/RTU.
10. Les désignations **Ports A–N** et des bornes (A1–A4, C1–C3, D1–D2, E1–E3, F2–F4, G1–G5, H1–H4, N1–N4) ainsi que les noms de signaux (RGND, Input, Output, +5V, +24V, GND, A+, B-, Pset A, Pset B, Sync In±, Sync Out±, Reset) restent en anglais en tant qu'inscriptions du matériel ; dans les titres de la section 8.2, « Port A : Contrôle de vitesse à distance » traduit le nom fonctionnel après le deux-points (espace fine française avant le deux-points), tandis que les inscriptions de circuit dans les alt restent en anglais.
11. Les noms de paramètres, symboles (U, A, a, E, J, L, t, h, E., u, n, y, r, Jd, Ld, rd, Γ5, Γ6, Γ8, Γd, ΓE, C, F, 1F, PA, 1A, G, GL, P, H, b, SP, c, Ur, ├, etc.) et valeurs affichées (0~250 (V), 25.0~400.0 (Hz), 0.0~99.9 (s), etc.) restent inchangés, s'agissant d'affichages et de réglages de l'appareil.
12. **Espaceurs vcrop** : les 9 espaceurs `[[vcrop:PAGE:IDX]]` de la maquette anglaise (15 références image après développement) ont été remplacés dans la version française par des références d'image explicites (`assets/images/cuh.sdvc34.manual.v0.0/page-00PP-vcrop-II.png`) ; la maquette anglaise reste inchangée.
13. **Images** : les 246 références d'image de la version française pointent vers des fichiers identiques à ceux de la maquette anglaise (`assets/images/cuh.sdvc34.manual.v0.0/`, 520 fichiers partagés) ; les 184 textes alt chinois résiduels ont été traduits en français suivant le précédent allemand (ex. « Symbole à sept segments du réglage Γ5 : trois barres de segments centrales » sur le modèle « Segmentanzeige-Symbol für Γ5-Einstellung »).
14. **Typographie** : guillemets français « » pour les guillemets droits du corps de texte (touches « ▲ », ports « N2 », paramètres « GL », affichage « SAVE », etc., précédent du lot) ; les deux-points du titre français portent une espace fine (« Étape un : ») ; les 29 lignes à double espace final sont conservées à l'identique (indicateurs L305~L335, L651, L805, convention L1387/L1388, vitesses préréglées L1756~L1758, RS485 L1799/L1800/L1811~L1813, bloc société L2044~L2049).
15. **Nombres et unités** : le point décimal du source est conservé (0.5V, 9.6 Kbps, 0.0~99.9 (s)) afin de rester cohérent avec les affichages de l'appareil et les tableaux techniques (8.3) ; unités V/Hz/s/°C/mA/VA/W/mm inchangées ; « 65°C » sans espace comme dans le source.
16. **Tableaux 8.3/8.4** : en-têtes traduits « Élément/Min/Typique/Max/Unité/Remarque » et « Phénomène de panne/Suggestions de dépannage/Image du symbole » ; le losange **◆** (U+25C6) et les codes Err01~Err11 sont repris tels quels ; « digital tube » rendu par « afficheur à sept segments affichant ErrNN ».
17. **Bloc société et identificateurs** : les 6 lignes finales d'informations société (avec doubles espaces finaux) restent en anglais ; « Document No.: IDP1000478 » et les deux commentaires HTML finaux ne sont pas traduits ; l'alt du code QR est rendu par « Code QR CUH ».
