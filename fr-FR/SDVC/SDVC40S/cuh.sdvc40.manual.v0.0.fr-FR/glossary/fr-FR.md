## 4. Décisions de convention de la traduction

1. **Contrôleur** comme dénomination continue de « the controller » ; le nom complet du produit est « Contrôleur numérique à fréquence variable pour alimentateur vibrant piézoélectrique » (cohérent avec le titre français de ce manuel).
2. **Alimentateur vibrant** pour « vibratory feeder » ; **vibrateur** pour « vibrator » ; **pièces** pour « work pieces ».
3. **Retard d'enclenchement / retard de déclenchement** pour « Startup Delay / Shutdown Delay » (J/J-, L/L-), conformément au lot français de la série ; **démarrage progressif** pour « Soft Startup », **temps de démarrage progressif** pour « Soft Startup Time ».
4. **Relation logique** pour « Logical Relation » ; les valeurs d'énumération **Normal Open / Normal Close**, **AND / OR / NOR** restent en anglais, s'agissant d'affichages de l'appareil.
5. Capteurs : **capteur photoélectrique intelligent** (SDVC-S1), **capteur de commutation NPN**, **capteur de proximité NPN**, **capteur à barrière** (counter-radiation), **capteur à fibre optique à barrière**, **capteur photoélectrique à réflexion** ; **automate (PLC)** pour « PLC », **DCS** conservé.
6. Les symboles et affichages de l'appareil (U, E, J, L, t, h, rd, r1–r3, A, J-, L-, Γ1–Γ3, Γd, 8.8.8.8.8., -----, Err01–Err05, FUNC, ON/OFF, Vol+/Vol-, ▲/▼, RST) ainsi que les désignations de bornes (A1–A3, B1–B4, C1–C3, D1–D2) et les inscriptions du matériel (« Output », « Shell Ground », « Output Pin », « Ground Wire », « Signal Wire », « +24V Output », « Blue− », « Brown+ », « Black OUT », « Ready to restore », « Restore successfully ») restent en anglais, entre guillemets « » dans les textes alt lorsque nécessaire.
7. **Images** : les 76 références d'image de la version française pointent vers des fichiers identiques à ceux de la maquette anglaise (`assets/images/cuh.sdvc40.manual.v0.0/`) ; la maquette anglaise ne contient aucun espaceur `[[vcrop]]` (0 occurrence), aucune substitution n'était donc nécessaire ; les 43 textes alt chinois résiduels (par ex. « CUH 二维码 » → « Code QR CUH », « 数码管错误显示 Err01 » → « Affichage numérique de l'erreur Err01 ») ont été traduits en français suivant le précédent allemand, les textes alt anglais (ex. « Controller with the upper cover plate open ») restant traduits en français comme textes descriptifs.
8. **Typographie** : guillemets français « » pour les libellés anglais cités ; les deux-points portent une espace insécable visuelle (« Remarque : ») ; les 23 lignes à double espace final (L38, L41, L162, L277, L280, L283, L286, L289, L292, L295, L298, L301, L342, L515, L528, L576, L577, bloc société L886–L891) sont conservées à l'identique ; la ligne de couverture à U+3000 (L23) est conservée.
9. **Ponctuation normalisée** : les 14 occurrences du point idéographique « 。 » sont rendues par « . » ; les 3 paires de parenthèses pleine largeur (L603, L781, L783) sont rendues en « ( ) » ; les défauts typographiques du source sont conservés (par ex. « .( » L32, « (E)Appuyez » L249, « ,et » L334, double point « (Γ 2) » L646 normalisé en un seul point).
10. **Nombres et unités** : dans le texte courant, les durées en secondes utilisent la virgule décimale française (0,1 s ; 2,0 secondes ; le lapse de temps) ; les valeurs d'affichage de l'appareil et les tableaux techniques (annexes D–F) conservent le point décimal et les unités du source (0.1 Hz, 0.5, 53.6 mm, V/Hz/s/°C/mA/VA/W).
