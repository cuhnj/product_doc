## 4. Décisions de convention de la traduction

1. **Contrôleur** comme dénomination continue de « the controller » ; le nom complet du produit est « Contrôleur numérique à fréquence variable pour alimentateur vibrant piézoélectrique » (cohérent avec le titre français de ce manuel).
2. **Alimentateur vibrant** pour « vibratory feeder » ; **vibrateur piézoélectrique** pour « piezo vibratory feeder » ; **pièces** pour « work pieces ».
3. **Retard d'enclenchement / retard de déclenchement** pour « On Delay / Off Delay » (angl. aussi « Startup/Shutdown Delay »), conformément au lot français de la série ; **temps de démarrage progressif / temps d'arrêt progressif** pour « Soft Startup Time / Soft Stop Time ».
4. **Direction logique** pour « Logical Direction » ; **relation logique** pour « Logical Relation » ; **logique du port de sortie principale** pour « Main Logic ». Les valeurs d'énumération **And / Or / Xor / RS**, **Const / Revrs / Inv / On / Off**, **Delay / Hold / Cycle1 / Cycle2**, **NPN / PNP / Auto0 / Auto1** restent en anglais, s'agissant d'affichages de l'appareil.
5. Capteurs : **capteur photoélectrique intelligent** (port B), **capteur de commutation** (port C), **capteur de proximité NPN**, **capteur à barrière**, **capteur à barrière à fibre optique** ; **automate (PLC)** pour « PLC », **DCS** conservé.
6. Les ports A–D restent des désignations d'appareil (port A = commande de vitesse à distance, port B = capteur photoélectrique intelligent, port C = capteur de commutation, port D = sortie de commande CC) ; de même RX/TX, RGND et les bornes A1–A3, B1–B4, C1–C3, D1–D3.
7. Les noms des groupes de paramètres (1EditHome, 2Common, 3M_output, 4PhotoSen, 5On&Off, 6DCoutput, 7Save, 8Monitor) et toutes les identités de paramètres (01.UsrVoltage … 10.Language, Monit 1 … Monit 16) restent inchangés, ainsi que les mnémoniques d'affichage (RUN, Work, UsrD1–UsrD3, None, Circ/Line/Soli, Ou_NPN/Ou_PNP/Ou_P&P, SetWord).
8. Les indications d'erreur et d'avertissement (Short, MainOrCu, OverHot, OverCold, PotDOrCu, 24VErr, 5VErr, MainRSEr, PotDRSEr) restent en anglais, ainsi que les inscriptions matérielles (« Speed Ctrl », « Photosensor », « Sensor », « Ctrl Output », « Output », « RGND », « 5V out », « 24V out », « Input », « GND »).
