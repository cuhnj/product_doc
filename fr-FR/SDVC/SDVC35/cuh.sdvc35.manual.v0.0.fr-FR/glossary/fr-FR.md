## 4. Décisions de convention de la traduction

1. **Contrôleur** comme dénomination continue de « the controller » ; le nom complet du produit est « Contrôleur automatique intelligent pour alimentateur vibrant » (cohérent avec le titre français de ce manuel).
2. **Alimentateur vibrant** pour « Vibratory Feeder » ; **vibrateur** pour « vibrator » ; **capteur de vibration** pour « Vibration Sensor ».
3. **Commande marche/arrêt** pour « ON/OFF Control » ; le nom de la touche « ON/OFF » est conservé tel quel (« bouton ON/OFF »).
4. **Retard d'enclenchement / retard de déclenchement** pour « Up Delay / Down Delay » (PortCUpDly/PortCDnDly, PortEUpDly/PortEDnDly, PortDUpDly/PortDDnDly, PortPUpDly/PortPDnDly, MaUP/MaDn), conformément au lot français de la série.
5. **Mode principal** pour « Main Mode » ; **mode Sync** conservé ; **contrôleur maître / contrôleur esclave** pour « Master/Slave Controller » ; **effet de battement** pour « beat effect ».
6. **Commande de vitesse à distance** pour « Remote Speed Control » ; **automate programmable** pour « PLC » (annexe G).
7. Les désignations **Ports A/C/D/E/F/H/P** et des bornes (A3–A5, C1–C3, D1–D3, E1–E3, F2/F4, H1–H4, P1–P3) ainsi que les noms de signaux (GND, Input, Output, +5V, +24V, A+, B-, Sync In±, Sync Out±) restent en anglais en tant qu'inscriptions du matériel ; l'annexe B reprend telle quelle la table de la maquette anglaise (Sensor, PortE, PortC, PortH, PortA, Ctrl Out, RS485, PortP, PortD, PortF, GND, Input, +24V, +5V, Output, Sync Out±, Sync In±, B-, A+), suivant le précédent allemand.
8. Les noms de paramètres, symboles et valeurs d'énumération (Usr_Voltag, PortDLogic, PortDSrc__, Const, Revrs, NPN, PNP, Ps&Pu, Manul, Auto, SlavC, SlavM, Work, UsrD1–UsrD3, RWork, None, Valid, Idle, Error...) ainsi que le contenu du menu de langue « Englsh<br>中文<br>dt » et « valid »/« Invalid » du test de charge (4.12) restent inchangés, s'agissant d'affichages et de réglages de l'appareil.
9. **Images** : les 51 références d'image de la version française pointent vers des fichiers identiques à ceux de la maquette anglaise (`assets/images/cuh.sdvc.manual.v0.0/`) ; la maquette anglaise ne contient aucun espaceur `[[vcrop]]` (0 occurrence), aucune substitution n'était donc nécessaire ; les 30 textes alt chinois résiduels (ex. « CUH 二维码 » → « Code QR CUH ») ont été traduits en français suivant le précédent allemand, les 21 alt anglais restant inchangés.
10. **Typographie** : guillemets français « » pour les guillemets droits du corps de texte (paramètres « User_Speed », valeurs « Auto », messages « OverCurrent »...) ; les deux-points du titre français portent une espace (« Remarque : ») ; les 8 lignes à double espace final (L662, L664, bloc société L1840~L1845) sont conservées à l'identique.
11. **Nombres et unités** : le point décimal du source est conservé (0.2 s, 30.0Hz, 9.999) afin de rester cohérent avec les affichages de l'appareil et les tableaux techniques ; unités V/Hz/s/°C/mA/VA/W/mm/H/Ω inchangées.
12. **Bloc société et identificateurs** : les 6 lignes finales d'informations société (avec doubles espaces finaux) restent en anglais ; « Document No.: IDP1000482 » et les deux commentaires HTML finaux ne sont pas traduits ; l'alt du code QR est rendu par « Code QR CUH ».
