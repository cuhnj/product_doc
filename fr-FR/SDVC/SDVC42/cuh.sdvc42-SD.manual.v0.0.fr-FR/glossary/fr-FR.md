## 4. Décisions de convention de la traduction

1. **Contrôleur** comme dénomination continue de « the controller » ; le nom complet du produit est « Contrôleur piézoélectrique automatique à haute fréquence » (cohérent avec le titre français de ce manuel).
2. **Alimentateur vibrant** pour « vibratory feeder » ; **capteur de vibration** pour « Vibration Sensor » ; **capteur d'accélération** pour « Acceleration Sensor » ; **capteur de commutation** pour « Switch Sensor ».
3. **ON/OFF** conservé pour l'inscription matérielle du bouton (bouton ON/OFF) ; **marche/arrêt** pour « on/off » dans le texte courant.
4. **Temps de démarrage progressif** / **temps d'arrêt progressif** pour « Soft Start Time » / « Soft Stop Time » (P2.04/P2.05) ; **temporisation de montée** / **temporisation de descente** pour « Rising/Falling Delay » (P3.04/P3.05) ; **temporisation de front montant** / **temporisation de front descendant** pour les « On Delay / Off Delay » des ports C/E, des vitesses A/B et du port D.
5. **Alarme de manque de matière** pour « Shortage Alarm » (P2.11, P10.38) ; **alarme d'arrêt** pour « Shutdown Alarm » (P2.12).
6. **Recherche automatique de la fréquence de résonance** pour « Automatic Resonant Frequency Search » (section 4.2) ; **interface de recherche de fréquence** pour « Frequency Search Interface » ; **vitesse d'alimentation constante** pour « Constant Feed Speed » (section 4.3).
7. **Contrôleur maître** / **contrôleur esclave** pour « Master/Slave Controller » ; **mise en réseau CUHBus-DS®** pour « CUHBus-DS® Networking ».
8. Les ports et bornes (T1–T3, A1–A4, C1–C3, D1–D3, E1–E3, F2–F4, N1/G/N/N4) ainsi que les désignations de signaux et de groupes (Sync±, RGND, Input, Output, 5V/24V Output, GND, A+, B-, Count/Speed A, Count/Speed B ; Digital Sync, Remote Speed Ctrl, Sensor, Sensor Ⅱ, Count/Speed Preset, RS485, Ctrl Out) restent en anglais, s'agissant d'inscriptions de l'appareil.
9. Les clés de paramètres P1.01–P10.45, les codes d'affichage (01.Monit1, 15.Language, etc.) et les valeurs d'énumération (And, Or, Xor, RS ; Const, Inv, On, Off ; Delay, Hold ; Manuel, Auto, SynV, SynE ; Panel, 20mA, 1-5V, 0-5V, 0-10V, DigSym ; Ou_PNP, Ou_NPN, Ou_P&P ; ManVol, RemVol, ManSpd, RemSpd, etc.) restent inchangés, s'agissant de textes d'affichage et de valeurs de réglage de l'appareil.

11. Format des nombres : dans le texte courant, virgule décimale française (par ex. 0,5 V ; 0,1 s) ; dans les tableaux et valeurs d'affichage, notation de la maquette anglaise conservée (par ex. 0.0~99.9 s ; 40.0~999.9 Hz ; 1~30 Mi, 31(allumé en permanence)).
