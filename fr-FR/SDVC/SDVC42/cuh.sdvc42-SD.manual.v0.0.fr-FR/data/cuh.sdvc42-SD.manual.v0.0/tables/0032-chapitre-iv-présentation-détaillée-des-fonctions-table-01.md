<!-- publish-data-sidecar: section=32 heading='4.4.2.1 Type de port D' role=generic source_md=doc.md -->

| Paramètre | Signification |
|---|---|
| Ou_NPN | Lorsque le signal de sortie du port D est valide, le port D émet un signal de niveau bas (0V) ; lorsqu'il est invalide, il est en haute impédance |
| Ou_PNP | Lorsque le signal de sortie du port D est valide, le port D émet un signal de niveau haut (24V) ; lorsqu'il est invalide, il est en haute impédance |
| Ou_P&P<br>(Push Pull) | Lorsque le signal de sortie du port D est valide, le port D émet un signal de niveau haut (24V). Lorsque le signal de sortie du port D est invalide, le port D émet un signal de niveau bas (0V) |
