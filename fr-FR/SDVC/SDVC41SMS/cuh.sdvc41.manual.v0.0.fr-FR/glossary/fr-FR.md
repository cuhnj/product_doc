## 4. Décisions de convention de la traduction

1. **Contrôleur** comme dénomination continue de « the controller » ; le nom complet du produit est « Contrôleur intelligent à fréquence variable pour alimentateur vibrant piézoélectrique » (cohérent avec le titre français de ce manuel).
2. **Alimentateur vibrant** pour « Vibratory Feeder » ; **alimentateur vibrant piézoélectrique** pour « Piezo Vibratory Feeder » ; **vibrateur** pour « vibrator » ; **capteur de vibration** pour « Vibration Sensor ».
3. **Commande marche/arrêt** pour « ON/OFF Control » (ports C et E, et commande marche/arrêt à distance) ; le bouton est rendu par **bouton ON/OFF** (libellé de l'appareil conservé, comme FUNC, Vol+ et Vol-) ; dans le tableau des vitesses préréglées, les combinaisons d'états sont rendues par **ON / OFF / Fermé / Ouvert**.
4. **Retard d'enclenchement / retard de déclenchement** pour « On Delay / Off Delay » (paramètres J/L des ports C et J-/L- des ports E).
5. **Temps de démarrage progressif** pour « Soft Startup Time » (paramètre t) ; **démarrage progressif** pour « Soft Startup » (fonction).
6. **Relation logique** pour « Logical Relation » ; **logique positive / logique négative** pour « Positive/Negative Logic » (`___` / `_-_`).
7. **Automate programmable** pour « PLC » (le sigle anglais n'est pas repris dans le texte français ; il subsiste dans les textes alt anglais des schémas, conservés tels quels).
8. Les désignations **Ports A–H** et des bornes (A1–A4, C1–C3, D1–D2, E1–E3, F2–F4, G1–G5, H1–H4) ainsi que les noms de signaux (RGND, Input, Output, +5V, +24V, GND, A+, B-, Speed A, Speed B, Input±, Output±) restent en anglais en tant qu'inscriptions du matériel.
9. Les noms de paramètres, symboles (U, A, a, E, J, L, t, J-, L-, Γ2–Γ8, ΓA, Π, h, C, F, n, IF, PA, IA, γ, μ, P, b, H, SP, c, Γd, Ur, etc.) et valeurs affichées (Uto, nPn, PnP, OR/AND/XOR, ASC/rtu, 0.0~20.0 s, 40.0~400.0 Hz, etc.) restent inchangés, s'agissant d'affichages et de réglages de l'appareil.
10. **Anomalies reprises de la maquette anglaise** : dans le tableau des paramètres de la section 4.4, les symboles Γ5/Γ6 apparaissent sous la forme « r5 »/« r6 » ; à l'étape 2 de la section 6.2.1.1, le texte mentionne « Connectez le capteur de proximité aux ports C » alors qu'il s'agit des ports E ; le titre de fin de la section 6.2 porte le numéro « 6.1.1.2 » au lieu d'un numéro 6.2.x ; ces anomalies sont conservées telles quelles, par fidélité à la maquette anglaise.
11. **Écran LED** pour « LED screen » ; les pictogrammes de l'afficheur sont désignés par « symbole à sept segments » dans les textes alt.
12. **Images** : les 189 références d'image de la version française pointent vers des fichiers identiques à ceux de la maquette anglaise (`assets/images/cuh.sdvc41.manual.v0.0/`) ; les 140 textes alt chinois résiduels ont été traduits en français suivant le précédent allemand ; les textes alt purement anglais sont conservés.
13. **Espaceurs vcrop** : les 21 espaceurs `[[vcrop:PAGE:IDX]]` de la maquette anglaise (pages 16, 28, 29, 31 et 48) ont été remplacés dans la version française par des références d'image explicites (`assets/images/cuh.sdvc41.manual.v0.0/page-00PP-vcrop-II.png`) ; la maquette anglaise reste inchangée.
14. **Nombres et unités** : virgule décimale dans le texte narratif (moins de 0,5 V ; 9,6 Kbps ; 0,1 Kbps) ; dans les affichages et les tableaux techniques (annexe C, plages de paramètres), la notation du source est conservée (0.0~20.0 s ; 40.0~400.0 Hz) ; unités V/Hz/s/°C/mA/VA/W/mm et « ℃ » inchangés.
15. **Typographie** : guillemets français « » pour les citations et libellés ; espace avant les deux-points (« Étape un : ») ; les 33 lignes à double espace final sont conservées à l'identique (voyants, boutons, blocs de tableau, bloc société).
16. **Pagination et identifiants** : la pagination « 1–60 » suit la maquette anglaise ; « Document No.: IDP1000544 » en fin de document reste inchangé ; le bloc société final reste en anglais (Nanjing CUH Science & Technology Co.,Ltd) pour préserver les contacts internationaux ; l'alt du code QR est « Code QR CUH ».
