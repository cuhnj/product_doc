## 4. Decisiones de convención de la traducción

- **Controlador** como denominación uniforme de "the controller"; la denominación completa del producto es "Controlador piezoeléctrico automático de alta frecuencia" (en: "Automatic High Frequency Piezo Controller"), coherente con el título de este manual.
- **Alimentador vibratorio** como versión en español de "vibratory feeder"; **vibrador piezoeléctrico** para "piezo vibrator".
- **Encendido/apagado** para "ON/OFF"; la tecla de arranque/parada se denomina **tecla de encendido/apagado**.
- **Tiempo de arranque suave** / **tiempo de parada suave** para "Soft Start Time" / "Soft Stop Time" (P2.04/P2.05); **retardo de subida/bajada de la salida principal** para "Main Output Rising/Falling Delay" (P3.04/P3.05).
- **Alarma de falta de material** para "Shortage Alarm" (P2.11) y "Low of Material Alarm" (P10.38); **alarma de parada** para "Shutdown Alarm" (P2.12).
- **Búsqueda automática de frecuencia resonante** para "Automatic Resonant Frequency Search" (sección 4.2); **interfaz de búsqueda de frecuencia** para "Frequency Search Interface".
- **Controlador maestro** / **controlador esclavo** para "Master/Slave Controller"; **red CUHBus-DS®** para "CUHBus-DS® Networking".
- **Pantalla de matriz de puntos** para "matrix display" (pantalla de matriz de puntos de 128 * 128).
- Los puertos y terminales (T1–T3, A1–A4, C1–C3, E1–E3, N1/G/N/N4, F2–F4, D1–D3), así como las denominaciones de señales y de grupos (Sync±, RGND, Input, 5V/24V Output, GND, A+, B-, Count/Pset A, Reset/Pset B, Count/Speed A/B; Digital Sync, Remote Speed Ctrl, Sensor, Sensor Ⅱ, Count/Speed Preset, RS485, Ctrl Out) se mantienen como denominaciones del dispositivo.
- Las claves de parámetros P1.01–P10.45, los códigos de visualización (01.Monit1, 15.Language, etc.) y los valores de enumeración (And, Or, Xor, RS; Const, Inv, On, Off, Keep; Delay, Hold; Manuel, Auto, SynV, SynE; Panel, 20mA, 1-5V, 0-5V, 0-10V, DigSym; Ou_PNP, Ou_NPN, Ou_P&P; ManVol, RemVol, ManSpd, RemSpd; Englis, Chines, German, etc.) permanecen sin cambios, ya que son textos de visualización y valores de ajuste del dispositivo.
- Referencias en las tablas de parámetros: **Véase el apéndice 7.4.11**.
- Formato numérico: se mantiene la escritura de la plantilla inglesa tanto en el texto narrativo como en tablas y valores de visualización (p. ej., 0.0~99.9 s; 5.0~999.9 Hz; 1~30 Mi, 31 (constantemente encendido); (unidades: 8h)); el símbolo ℃ (U+2103) se mantiene tal cual.
- En las tablas de códigos de error y de advertencia se mantienen los nombres de código y las visualizaciones (Short, OvrCurrt, Saturate, decline, etc.); los avisos de seguridad siguen la plantilla (Peligro/Advertencia/Aviso).
- Las respuestas del capítulo de preguntas frecuentes comienzan con **Solución:**.
