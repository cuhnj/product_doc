| อาการเสีย | ข้อเสนอแนะการแก้ไขปัญหา | ภาพสัญลักษณ์ |
|---|---|---|
| จอ LED ไม่แสดงผลหลังจากเปิดเครื่อง | ● ตรวจสอบให้แน่ใจว่าเต้ารับไฟเมนมีกระแสไฟฟ้า<br>● ตรวจสอบให้แน่ใจว่าสายไฟอินพุตเชื่อมต่ออย่างแน่นหนา | |
| จอ LED แสดงผลปกติ แต่ถาดป้อนแบบสั่นสะเทือนไม่มีเอาต์พุตหรือเสียง | ● ตรวจสอบให้แน่ใจว่าสายไฟเอาต์พุตเชื่อมต่ออย่างแน่นหนา<br>● ตรวจสอบให้แน่ใจว่าแรงดันเอาต์พุตไม่ต่ำเกินไป<br>● ตรวจสอบให้แน่ใจว่าตัวควบคุมไม่ได้ถูกหยุดโดยปุ่มเปิด/ปิดเมื่อไฟแสดงสถานะหยุดติดสว่าง<br>● ตรวจสอบให้แน่ใจว่าตัวควบคุมไม่ได้ถูกหยุดโดยสัญญาณควบคุมเปิด/ปิดเมื่อไฟแสดงสถานะหยุดติดสว่าง<br>● ตรวจสอบให้แน่ใจว่าตัวควบคุมไม่ได้ถูกหยุดโดยการตั้งค่าพารามิเตอร์ Γ2 หรือ Γ7 เมื่อไฟแสดงสถานะหยุดติดสว่าง<br>● รีเซ็ตตัวควบคุม | |
| การควบคุมเปิด/ปิดไม่ทำงาน | ● ตรวจสอบให้แน่ใจว่าสัญญาณควบคุมเปิด/ปิดเชื่อมต่อกับตัวควบคุมอย่างถูกต้อง<br>● ตรวจสอบให้แน่ใจว่าพารามิเตอร์ Γ2, Γ7 และ Π ถูกตั้งค่าอย่างถูกต้องตามความต้องการในการควบคุมของคุณ<br>● รีเซ็ตตัวควบคุม | |
| ปรากฏการณ์บีต | ● เชื่อมต่อสายสัญญาณซิงค์ระหว่างตัวควบคุม และตั้งค่าตัวควบคุมรองเป็นโหมดซิงค์ | |
| จอ LED แสดงผลปกติ ได้ยินเสียงจากถาดป้อนแบบสั่นสะเทือน แต่ไม่มีเอาต์พุต | ● ตรวจสอบให้แน่ใจว่าความถี่เอาต์พุตไม่ห่างจากความถี่เรโซแนนซ์ของถาดป้อนแบบสั่นสะเทือนมากนัก<br>● รีเซ็ตตัวควบคุม | |
