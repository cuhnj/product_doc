| สัญญาณควบคุมความเร็วระยะไกล | แรงดันเอาต์พุต/ความเร็วป้อน |
|---|---|
| น้อยกว่า 0.5V | ควบคุมด้วยปุ่ม Vol+ และ Vol- |
| 0.5V-1V | แรงดันเอาต์พุต: 20V/ความเร็วป้อน: 0<br>ควบคุมด้วยสัญญาณควบคุมความเร็วระยะไกล |
| 1~5V/4~20mA | แรงดันเอาต์พุต/ความเร็วป้อนถูกควบคุม<br>เชิงเส้นด้วยสัญญาณควบคุมความเร็วระยะไกล |
