## 4. แนวทางการตัดสินใจในการแปล

- **ตัวควบคุม** เป็นคำที่ใช้อย่างสม่ำเสมอสำหรับ "the controller"; ชื่อผลิตภัณฑ์ฉบับเต็มคือ "ตัวควบคุมอัจฉริยะแบบปรับความถี่ได้สำหรับเครื่องป้อนวัสดุแบบสั่นสะเทือนพีโซอิเล็กทริก" (สอดคล้องกับชื่อเรื่องภาษาไทยของคู่มือฉบับนี้)
- **เครื่องป้อนวัสดุแบบสั่นสะเทือน** เป็นคำแปลภาษาไทยของ "Vibratory Feeder"; "Piezo Vibratory Feeder" ใช้ **เครื่องป้อนวัสดุแบบสั่นสะเทือนพีโซอิเล็กทริก**; ในบางบริบทที่กล่าวถึงอุปกรณ์โดยทั่วไปใช้ **ถาดป้อนแบบสั่นสะเทือน** ตามที่ปรากฏในคู่มือฉบับนี้
- **เปิด/ปิด** สำหรับ "ON/OFF" (เช่น การควบคุมเปิด/ปิด, สัญญาณควบคุมเปิด/ปิด); ปุ่ม "ON/OFF button" ใช้ **ปุ่มเปิด/ปิด**; ในตารางความเร็วที่ตั้งไว้ล่วงหน้า สถานะสวิตช์ใช้ **เปิด / ปิดวงจร / ปิด / เปิดวงจร** (ON / Closed / OFF / Open)
- **เวลาหน่วงเปิด** / **เวลาหน่วงปิด** สำหรับ "On Delay" / "Off Delay" (พารามิเตอร์ J/L และ J-/L-)
- **เวลาสตาร์ทแบบนุ่มนวล** สำหรับ "Soft Startup Time" (พารามิเตอร์ t)
- **ความสัมพันธ์ทางลอจิก** สำหรับ "Logical Relation"; **ลอจิกเชิงบวก/ลอจิกเชิงลบ** สำหรับ "Positive/Negative Logic" (`___` / `_-_`)
- **พอร์ต A–H** และชื่อขั้วต่อ (A1–A4, C1–C3, D1–D2, E1–E3, F2–F4, G1–G5, H1–H4) รวมทั้งชื่อสัญญาณ (RGND, Input, Output, +5V, +24V, GND, A+, B-, Speed A, Speed B) คงไว้เป็นชื่อเฉพาะของอุปกรณ์
- ชื่อพารามิเตอร์ สัญลักษณ์ (U, A, a, E, J, L, t, J-, L-, Γ2–Γ8, ΓA, Π, h, C, F, n, IF, PA, IA, μ, γ, P, b) และค่าที่แสดง (Uto, nPn, PnP, OR/AND/XOR, ASC/rtu, 0.0~20.0 s, 40.0~400.0 Hz ฯลฯ) คงไว้ไม่เปลี่ยนแปลง เนื่องจากเป็นข้อความบนจอแสดงผลและค่าตั้งของอุปกรณ์
- หมายเหตุ: ในตารางพารามิเตอร์ของหัวข้อ 4.4 สัญลักษณ์ Γ5/Γ6 ปรากฏในรูปแบบ "r5"/"r6" ซึ่งถ่ายทอดตามต้นฉบับภาษาอังกฤษโดยไม่แก้ไข
- **จอ LED** สำหรับ "LED screen"; **จอแสดงผลแบบเซกเมนต์** สำหรับ "digital tube / seven-segment display"
- **ตัวแทน vcrop**: ตัวแทน `[[vcrop:PAGE:IDX]]` จำนวน 21 จุดของต้นฉบับภาษาอังกฤษถูกแทนที่ในฉบับภาษาไทยด้วยลิงก์รูปภาพที่สอดคล้องกัน (`assets/images/cuh.sdvc41.manual.v0.0/page-00PP-vcrop-II.png` หน้า 16, 28, 29, 31, 48); ต้นฉบับภาษาอังกฤษคงไว้ไม่เปลี่ยนแปลง
- รูปแบบตัวเลข: ฉบับภาษาไทยใช้จุดทศนิยมตามต้นฉบับภาษาอังกฤษทั้งในเนื้อความและในตาราง (เช่น 0.2 วินาที; 9.6 Kbps); ค่าที่แสดงบนอุปกรณ์และตารางข้อมูลทางเทคนิค (ภาคผนวก C, ช่วงพารามิเตอร์) คงรูปแบบและหน่วยตามต้นฉบับ (เช่น 0.0~20.0 s)
- การนับหน้า "หน้า 1–60" เป็นไปตามต้นฉบับภาษาอังกฤษ; เลขที่เอกสาร "เลขที่เอกสาร: IDP1000544" ท้ายเอกสารคงไว้ไม่เปลี่ยนแปลง
