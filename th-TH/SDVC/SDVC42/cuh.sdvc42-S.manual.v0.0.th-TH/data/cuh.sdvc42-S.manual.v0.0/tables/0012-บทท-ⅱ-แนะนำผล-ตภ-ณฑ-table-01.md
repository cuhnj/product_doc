| รายการบนหน้าหลัก | ตัวอย่างที่แสดง | คำอธิบาย |
|---|---|---|
| สถานะเอาต์พุตหลัก | `RUN` | แสดงสถานะเอาต์พุตหลักปัจจุบัน |
| สถานะพอร์ต | `A C D E F G N J    A0` | แสดงสถานะของพอร์ต `A`: สถานะเครือข่าย; `0`: หมายเลขอุปกรณ์ |
| พารามิเตอร์ตรวจสอบ 1 | `UserSped` / `P2.01` / `200` | ค่าพารามิเตอร์ตรวจสอบที่แสดงบนหน้าหลัก |
| พารามิเตอร์ตรวจสอบ 2 | `UserVoltg` / `P2.02` / `150` | การเลือกแบบผกผันหมายความว่าค่าพารามิเตอร์สามารถปรับได้ และสามารถเปลี่ยนแรงดันไฟฟ้าเอาต์พุตหลักได้ |
| พารามิเตอร์ตรวจสอบ 1 | `UserSped` / `P2.01` / `200` ในกล่องกาเครื่องหมาย | กล่องกาเครื่องหมายหมายความว่าค่าพารามิเตอร์สามารถปรับได้ แต่ไม่สามารถเปลี่ยนแรงดันไฟฟ้าเอาต์พุตได้ เนื่องจากไม่ได้ต่อเซ็นเซอร์ความเร่ง |
| การปรับพารามิเตอร์ +/- | `+` / `-` | ตัวควบคุมการปรับค่าพารามิเตอร์ |
| ชื่ออินเตอร์เฟซ | `Home` | ชื่ออินเตอร์เฟซปัจจุบัน |
