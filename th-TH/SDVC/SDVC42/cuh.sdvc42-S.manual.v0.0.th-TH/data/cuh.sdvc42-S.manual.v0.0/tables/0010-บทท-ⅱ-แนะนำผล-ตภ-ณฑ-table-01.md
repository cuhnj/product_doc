<!-- publish-data-sidecar: section=10 heading='2.2 แผงปุ่มและพอร์ต I/O' role=generic source_md=doc.md -->

| องค์ประกอบ | คำอธิบาย |
|---|---|
| ปุ่มเพิ่มและลด | ใช้สำหรับแก้ไขค่าพารามิเตอร์ |
| ปุ่มขึ้นและลง | ใช้สำหรับสลับไปยังพารามิเตอร์ก่อนหน้าหรือถัดไปภายในกลุ่มพารามิเตอร์ |
| ปุ่มซ้ายและขวา | ใช้สำหรับสลับกลุ่มพารามิเตอร์และสลับระหว่างอินเตอร์เฟซบันทึกต่าง ๆ |
| จอเมทริกซ์จุด 128 * 128 | แสดงสัญลักษณ์พารามิเตอร์และค่าของพารามิเตอร์ |
| ปุ่มเปิด/ปิด | กดแบบสั้นเพื่อเริ่ม/หยุดเอาต์พุต กดค้างไว้เพื่อล็อกแป้นพิมพ์ |
