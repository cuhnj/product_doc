| พารามิเตอร์ | ความหมาย |
|---|---|
| Const | สถานะหลังการดำเนินการลอจิกเอาต์พุตหลักไม่ถูกกลับค่า โดยค่าเริ่มต้นเป็นสถานะปกติ |
| Inv | สถานะจะถูกกลับค่าหลังการดำเนินการลอจิกเอาต์พุตหลัก |
| On | สถานะยังคงทำงานต่อไปหลังการดำเนินการลอจิกเอาต์พุตหลัก |
| Off | สถานะหยุดเสมอหลังการดำเนินการลอจิกเอาต์พุตหลัก |
