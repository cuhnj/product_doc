## 4. แนวทางการตัดสินใจในการแปล

- **ตัวควบคุม** เป็นคำที่ใช้อย่างสม่ำเสมอสำหรับ "the controller"; ชื่อผลิตภัณฑ์ฉบับเต็มคือ "ตัวควบคุมดิจิทัลควบคุมความถี่สำหรับเครื่องป้อนวัสดุแบบสั่นสะเทือน" (สอดคล้องกับชื่อเรื่องภาษาไทยของคู่มือฉบับนี้)
- **เครื่องป้อนวัสดุแบบสั่นสะเทือน** เป็นคำแปลภาษาไทยของ "vibratory feeder"
- **เปิด/ปิด** สำหรับ "ON/OFF"; ปุ่มเปิด/ปิดเรียกว่า **ปุ่มเปิด/ปิดเอาต์พุต**
- **การสตาร์ทแบบนุ่มนวล** สำหรับ "Soft Startup"; **เวลาการสตาร์ทแบบนุ่มนวล** สำหรับ "Soft Startup Time"
- **การควบคุมความเร็วระยะไกล** สำหรับ "Remote Speed Control"; วิธีเชื่อมต่อที่เกี่ยวข้อง (โพเทนชิออมิเตอร์, 1~5V, 4~20mA) เป็นไปตามต้นฉบับ
- ชื่อพอร์ตและเทอร์มินัล (A1~A3, B1~B4, C1~C3, D1~D2, I1~I2; Speed Ctrl, Photosensor, Sensor, Ctrl Out, RGND, Input, 5V out, GND, RX, TX, 24V out, Output, 24V DC) คงไว้เป็นชื่อเฉพาะของอุปกรณ์ตามต้นฉบับภาษาอังกฤษ
- สัญลักษณ์พารามิเตอร์ (U, E, J, L, t, L-, J-, F1~F4, n, H, y, r, P, FA, C, e, 8.8.8.8.8., Pin) และค่าตัวเลือก (nPn, PnP, ut0, ut1; And, or, Xor) คงไว้ไม่เปลี่ยนแปลง เนื่องจากเป็นข้อความบนจอแสดงผลและค่าตั้งของอุปกรณ์
- รูปแบบตัวเลขและหน่วยคงไว้ตามต้นฉบับภาษาอังกฤษ (เช่น 0.0~20.0 s; 40.0~400.0 Hz; 0~260 V; 85~250 VAC)
- ข้อความความปลอดภัยใช้ตามต้นฉบับ: **⚠ อันตราย / ⚠ คำเตือน / ⚠ ข้อควรระวัง / ข้อสังเกต / ❗ จำเป็น**
- รหัสข้อผิดพลาด (Err01 … Err11) คงไว้ไม่เปลี่ยนแปลง
