| รหัสข้อผิดพลาด | คำจำกัดความ | วิธีการแก้ไขปัญหา | ภาพสัญลักษณ์ |
|---|---|---|---|
| ไม่มีการแสดงผลหลังจากเปิดไฟ | | ตรวจสอบให้แน่ใจว่าเต้ารับไฟมีไฟฟ้า<br>ตรวจสอบให้แน่ใจว่าสายไฟขาเข้าเสียบเข้าเต้ารับไฟอย่างมั่นคงหรือไม่? | | |
| แสดงผลตามปกติ แต่ไม่มีเอาต์พุต | | ตรวจสอบให้แน่ใจว่าสายเอาต์พุตเสียบเข้ากับตัวสั่นสะเทือนอย่างมั่นคง<br>ตรวจสอบให้แน่ใจว่าแรงดันไฟฟ้าขาออกไม่ต่ำเกินไป<br>ตรวจสอบให้แน่ใจว่าไฟแสดงสถานะหยุดทำงานไม่ได้สว่างขึ้น<br>โปรดตรวจสอบว่ามีการตั้งค่าพารามิเตอร์แบบปกติปิดไว้หรือไม่ ซึ่งทำให้เอาต์พุตของตัวควบคุมหยุดทำงาน | | |
| สัญญาณควบคุมไม่มีผล | | ตรวจสอบให้แน่ใจว่าสัญญาณควบคุมถูกป้อนเข้าอย่างถูกต้อง<br>ตรวจสอบให้แน่ใจว่าสายกราวด์ของสัญญาณควบคุมต่อเข้ากับตัวควบคุมอย่างถูกต้อง<br>ตรวจสอบให้แน่ใจว่าความสัมพันธ์เชิงตรรกะของสัญญาณควบคุมถูกตั้งค่าถูกต้องตามที่คาดหวัง | | |
| ปรากฏการณ์บีต | | หลีกเลี่ยงการส่งผ่านการสั่นสะเทือนระหว่างตัวสั่นสะเทือน<br>เพิ่มความถี่การสั่นพ้องของตัวสั่นสะเทือนให้สูงขึ้น | | |
| แสดงผลตามปกติ ไม่มีเอาต์พุต แต่ได้ยินเสียง | | ปรับพารามิเตอร์ทั้งหมดตามที่คู่มือเล่มนี้แนะนำ | | |
| Err01 | การลัดวงจร | ตรวจสอบให้แน่ใจว่าโหลดไม่ถูกลัดวงจร จากนั้นลองเริ่มเอาต์พุตของตัวควบคุมใหม่โดยกดปุ่มเปิด/ปิดเอาต์พุตสองครั้ง หรือจ่ายไฟใหม่ให้ตัวควบคุม | ![ภาพสัญลักษณ์ Err01](assets/images/cuh.sdvc311.manual.v0.0/page-0046-vcrop-00.png) |
| Err02 | กระแสเกิน | ลดแรงดันไฟฟ้าขาออกลงอย่างเหมาะสม แล้วเริ่มเอาต์พุตใหม่ | ![ภาพสัญลักษณ์ Err02](assets/images/cuh.sdvc311.manual.v0.0/page-0046-vcrop-01.png) |
| Err03 | ความร้อนสูงเกินไป | ติดตั้งตัวควบคุมไว้ในสภาพแวดล้อมที่มีการระบายอากาศที่ดี | ![ภาพสัญลักษณ์ Err03](assets/images/cuh.sdvc311.manual.v0.0/page-0046-vcrop-02.png) |
| Err04 | แรงดันไฟฟ้าสูงเกินไปหรือต่ำเกินไป | ตรวจสอบให้แน่ใจว่าแรงดันไฟฟ้าขาเข้าอยู่ระหว่าง AC 85~250Vac | ![ภาพสัญลักษณ์ Err04](assets/images/cuh.sdvc311.manual.v0.0/page-0046-vcrop-03.png) |
| Err05 | การสื่อสารภายในผิดปกติ | ตรวจสอบให้แน่ใจว่าไม่มีแหล่งจ่ายไฟภายนอกต่อเข้ากับพอร์ตจ่ายไฟ 24V หรือติดต่อฝ่ายสนับสนุนทางเทคนิคของเรา | ![ภาพสัญลักษณ์ Err05](assets/images/cuh.sdvc311.manual.v0.0/page-0046-vcrop-04.png) |
| Err06 | เซ็นเซอร์วัดอุณหภูมิผิดปกติ | ตรวจสอบให้แน่ใจว่าอุณหภูมิในการทำงานไม่ต่ำกว่า -20℃ หรือติดต่อฝ่ายสนับสนุนทางเทคนิคของเรา | ![ภาพสัญลักษณ์ Err06](assets/images/cuh.sdvc311.manual.v0.0/page-0046-vcrop-05.png) |
| Err07 | การป้องกันการลัดวงจรของพอร์ต D | ตรวจสอบให้แน่ใจว่าโหลดของพอร์ต D ไม่ถูกลัดวงจรและกระแสไม่เกิน 400mA จากนั้นลองเริ่มเอาต์พุตของพอร์ต D ใหม่ | ![ภาพสัญลักษณ์ Err07](assets/images/cuh.sdvc311.manual.v0.0/page-0046-vcrop-06.png) |
| Err10 | เอาต์พุตจ่ายไฟ 24V ผิดปกติ | ตรวจสอบให้แน่ใจว่าพอร์ต 24V ไม่ถูกลัดวงจรและกระแสไม่เกิน 400mA | ![ภาพสัญลักษณ์ Err10](assets/images/cuh.sdvc311.manual.v0.0/page-0046-vcrop-07.png) |
| Err11 | เอาต์พุตจ่ายไฟ 5V ของพอร์ต A ผิดปกติ | ตรวจสอบให้แน่ใจว่าแหล่งจ่ายไฟ 5V ของพอร์ต A ไม่ถูกลัดวงจร หรือไม่ได้ต่อเข้ากับแรงดันไฟฟ้าภายนอกที่สูงกว่า 5V | ![ภาพสัญลักษณ์ Err11](assets/images/cuh.sdvc311.manual.v0.0/page-0046-vcrop-08.png) |
