| 1 | ไม่มีการแสดงผลหลัง<br>เปิดเครื่อง |  | ◆ ตรวจสอบให้แน่ใจว่าเต้ารับไฟฟ้ามีกระแส<br>◆ ตรวจสอบให้แน่ใจว่าสายไฟเข้าเชื่อมต่อกับเต้ารับไฟฟ้าอย่างเชื่อถือได้ |
| 2 | แสดงผลปกติ<br>แต่ไม่มีเอาต์พุต |  | ◆ ตรวจสอบให้แน่ใจว่าสายไฟเข้าและสายไฟเอาต์พุตเชื่อมต่อแน่น<br>◆ ตรวจสอบให้แน่ใจว่าค่าพารามิเตอร์แรงดันไฟฟ้าขาออกไม่เล็กเกินไป<br>◆ ตรวจสอบให้แน่ใจว่าตัวควบคุมไม่ได้ถูกหยุดโดยสัญญาณควบคุม<br>◆ ตรวจสอบให้แน่ใจว่าตัวควบคุมไม่ได้ถูกหยุดโดยพารามิเตอร์ที่ตั้งเป็นการปิดปกติ |
| 3 | สัญญาณควบคุม<br>สูญเสียประสิทธิภาพ |  | ◆ ตรวจสอบให้แน่ใจว่าสัญญาณควบคุมถูกป้อนเข้าอย่างถูกต้อง<br>◆ ตรวจสอบให้แน่ใจว่าสายดินของสัญญาณควบคุมเชื่อมต่อกับตัวควบคุมอย่างถูกต้อง<br>◆ ตรวจสอบให้แน่ใจว่าความสัมพันธ์เชิงตรรกะของสัญญาณควบคุมตั้งค่าถูกต้องตามที่คุณต้องการ |
| 4 | ปรากฏการณ์เต้น (Beat) |  | ◆ หลีกเลี่ยงการสั่นสะเทือนส่งผ่านระหว่างตัวสั่น<br>◆ เพิ่มความถี่เสียงสะท้อนของตัวสั่น |
| 5 | แสดงผลปกติ<br>ไม่มีเอาต์พุต แต่<br>ได้ยินเสียง |  | ◆ ปรับพารามิเตอร์ทั้งหมดตามที่คู่มือเล่มนี้แนะนำ |
