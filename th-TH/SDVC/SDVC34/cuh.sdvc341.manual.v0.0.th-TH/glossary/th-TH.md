## 4. แนวทางการตัดสินใจในการแปล

- **ตัวควบคุม** เป็นคำที่ใช้อย่างสม่ำเสมอสำหรับ "the controller"; ชื่อผลิตภัณฑ์ฉบับเต็มคือ "ตัวควบคุมความถี่อัตโนมัติสำหรับเครื่องป้อนวัสดุแบบสั่นสะเทือน" (สอดคล้องกับชื่อเรื่องภาษาไทยของคู่มือฉบับนี้)
- **เครื่องป้อนวัสดุแบบสั่นสะเทือน** เป็นคำแปลภาษาไทยของ "Vibratory Feeder"
- **เปิด/ปิด** สำหรับ "ON/OFF"; ปุ่ม "ON/OFF" ใช้ **ปุ่มเปิด/ปิด**
- **เวลาสตาร์ทแบบนุ่มนวล** / **เวลาหยุดแบบนุ่มนวล** สำหรับ "Soft Start Time" / "Soft Stop Time" (P2.04/P2.05); **การหน่วงเปิดหลัก** / **การหน่วงปิดหลัก** สำหรับ "Main Output Rising/Falling Delay" (P3.04/P3.05)
- **การแจ้งเตือนวัสดุขาดแคลน** สำหรับ "Shortage Alarm" (P2.11, P10.36); **การแจ้งเตือนการปิดเครื่อง** สำหรับ "Shutdown Alarm" (P2.12)
- **การค้นหาความถี่เรโซแนนซ์อัตโนมัติ** สำหรับ "Automatic Resonant Frequency Search" (หัวข้อ 4.2); **อินเทอร์เฟซการค้นหาความถี่** สำหรับ "Frequency Search Interface"
- **ตัวควบคุมหลัก** / **ตัวควบคุมทาส** สำหรับ "Master/Slave Controller"; **การเชื่อมต่อเครือข่าย CUHBus-DS®** สำหรับ "CUHBus-DS® Networking"
- **จอแบบดอทเมทริกซ์** สำหรับ "matrix display" (จอแบบดอทเมทริกซ์ 128 * 128)
- พอร์ตและขั้วต่อ (T1–T3, A1–A4, C1–C3, E1–E3, N1/G/N/N4, F2–F4, D1–D3) รวมทั้งชื่อสัญญาณและชื่อกลุ่มฟังก์ชัน (Sync±, RGND, Input, 5V/24V Output, GND, A+, B-, Count/Pset A, Reset/Pset B; Digital Sync, Remote Speed Ctrl, Sensor, Sensor II, Count/Speed Preset, RS485, Ctrl Out) คงไว้เป็นชื่อเฉพาะของอุปกรณ์
- รหัสพารามิเตอร์ P1.01–P10.43 รหัสการแสดงผล (01.Monit1, 15.Language ฯลฯ) และค่าตัวเลือก (And, Or, Xor, RS; Const, Inv, On, Off; Delay, Hold; Manuel, Auto, SynV, SynE; Panel, 20mA, 1-5V, 0-5V, 0-10V, DigSym; Ou_PNP, Ou_NPN, Ou_P&P; ManVol, RemVol, ManSpd, RemSpd ฯลฯ) คงไว้ไม่เปลี่ยนแปลง เนื่องจากเป็นข้อความบนจอแสดงผลและค่าตั้งของอุปกรณ์
- การอ้างอิงในตารางพารามิเตอร์: **ดูภาคผนวก 7.4.11**.
- รูปแบบตัวเลข: ในเนื้อความใช้จุดทศนิยมตามต้นฉบับภาษาอังกฤษ (เช่น 0.1 วินาที, 0.5 วินาที); ในตารางและค่าที่แสดงคงรูปแบบเดิม (เช่น 0.0~99.9 s; 5.0~999.9 Hz; 1~30 Mi，31(สว่างตลอดเวลา))
