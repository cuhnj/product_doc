## 4. ข้อตัดสินใจเชิงอนุสัญญาของการแปล

- **ตัวควบคุม** เป็นคำเรียกตลอดทั้งเล่มสำหรับ "the controller" ชื่อผลิตภัณฑ์เต็มคือ "ตัวควบคุมความถี่ดิจิทัลแบบปรับค่าได้สำหรับเครื่องป้อนวัสดุแบบสั่นสะเทือนพีโซอิเล็กทริก" สอดคล้องกับหัวเรื่องผลิตภัณฑ์ภาษาไทยของคู่มือเล่มนี้
- **เครื่องป้อนวัสดุแบบสั่นสะเทือน** เป็นคำแปลของ "Vibratory Feeder"; "Piezo Vibratory Feeder" แปลว่า **เครื่องป้อนวัสดุแบบสั่นสะเทือนพีโซอิเล็กทริก**
- **เวลาสตาร์ทแบบนุ่มนวล** / **เวลาหยุดแบบนุ่มนวล** สำหรับ "Soft Startup Time" / "Soft Stop Time"
- **เวลาหน่วงเปิด** / **เวลาหน่วงปิด** สำหรับ "On Delay" / "Off Delay" (หรือ "Startup/Shutdown Delay" ในต้นฉบับ)
- **ทิศทางลอจิก** สำหรับ "Logical Direction"; **ความสัมพันธ์ทางตรรกะ** สำหรับ "Logical Relation" ของการเชื่อมสัญญาณ (And/Or/Xor/RS)
- **พอร์ต A–D** คงไว้เป็นชื่อเรียกของอุปกรณ์ (พอร์ต A = การควบคุมความเร็วระยะไกล, พอร์ต B = เซ็นเซอร์โฟโต้อิเล็กทริกอัจฉริยะ, พอร์ต C = เซ็นเซอร์สวิตช์, พอร์ต D = เอาต์พุตควบคุม DC) รวมถึง RX/TX และหมายเลขขั้วต่อ A1–A3, B1–B4, C1–C3, D1–D3
- ชื่อกลุ่มพารามิเตอร์บนอุปกรณ์และรหัสพารามิเตอร์ทั้งหมดคงรูปเดิม (1EditHome, 2Common, 3M_output, 4PhotoSen, 5On&Off, 6DCoutput, 7Save, 8Monitor; 01.UsrVoltage … 10.Language เป็นต้น) เนื่องจากเป็นสิ่งที่อุปกรณ์แสดงบนจอภายใน
- สถานะและคำสัญญาณบนจอคงรูปเดิม (RUN, Const/Revrs/Inv/On/Off, And/Or/Xor/RS, Delay/Hold/Cycle1/Cycle2, NPN/PNP/Auto0/Auto1, Ou_NPN/Ou_PNP/Ou_P&P, Circ/Line/Soli เป็นต้น)
- รหัสข้อผิดพลาดและคำเตือน (Short, MainOrCu, OverHot, OverCold, PotDOrCu, 24VErr, 5VErr, MainRSEr, PotDRSEr) คงรูปเดิม
- กล่องคำเตือน: ใช้คำสัญญาณตามคำอธิบายสัญลักษณ์ในบทนำ — "⚠ อันตราย", "⚠ คำเตือน", "⚠ ข้อควรระวัง", "ข้อสังเกต" และ "❗ จำเป็น"; คำว่า "Notice" ในหัวข้อย่อยแปลว่า "**ข้อสังเกต**"
- รูปแบบตัวเลข: ข้อความบรรยายใช้จุดทศนิยม (เช่น 0.2 วินาที) ตามธรรมเนียมภาษาไทย; ค่าที่จอแสดงและตารางข้อมูลทางเทคนิค (หัวข้อ 7.4) คงรูปแบบและหน่วยของต้นฉบับภาษาอังกฤษ เนื่องจากเป็นค่าที่อุปกรณ์แสดง/ค่าในตาราง
