| รหัสข้อผิดพลาด | คำจำกัดความ | วิธีการแก้ไขปัญหา | ภาพสัญลักษณ์ |
|---|---|---|---|
| ไม่มีจอแสดงผลหลังเปิดเครื่อง | | ตรวจสอบว่าปลั๊กไฟมีไฟฟ้า<br>ตรวจสอบว่าสายไฟขาเข้าเชื่อมต่อกับปลั๊กไฟอย่างแน่นหนาหรือไม่ | |
| จอแสดงผลปกติ แต่ไม่มีเอาต์พุต | | ตรวจสอบว่าสายไฟขาออกเชื่อมต่อกับเครื่องสั่นอย่างแน่นหนา<br>ตรวจสอบว่าแรงดันไฟฟ้าขาออกไม่น้อยเกินไป<br>ตรวจสอบว่าไฟแสดงการหยุดไม่ติดสว่าง<br>โปรดตรวจสอบว่ามีการตั้งค่า Normal Close ของพารามิเตอร์หรือไม่ ซึ่งทำให้เอาต์พุตของตัวควบคุมหยุดลง | |
| สัญญาณควบคุมไม่ทำงาน | | ตรวจสอบว่าอินพุตสัญญาณควบคุมถูกต้อง<br>ตรวจสอบว่าสายดินของสัญญาณควบคุมเชื่อมต่อกับตัวควบคุมอย่างถูกต้อง<br>ตรวจสอบว่าความสัมพันธ์ทางลอจิกของสัญญาณควบคุมตั้งค่าไว้ตรงตามที่คาดหวังอย่างถูกต้อง | |
| ปรากฏการณ์บีต | | หลีกเลี่ยงการเชื่อมต่อการสั่นสะเทือนระหว่างเครื่องสั่น<br>เพิ่มความถี่เรโซแนนซ์ของเครื่องสั่น | |
| จอแสดงผลปกติ ไม่มีเอาต์พุต แต่ได้ยินเสียง | | ปรับพารามิเตอร์ทั้งหมดตามคำแนะนำในคู่มือนี้ | |
| Err01 | ไฟฟ้าลัดวงจร | ตรวจสอบว่าโหลดไม่ได้ลัดวงจร จากนั้นลองรีสตาร์ทเอาต์พุตของตัวควบคุมโดยกดปุ่มเปิด/ปิดสองครั้งหรือเปิดเครื่องใหม่ | ![จอแสดงผลเจ็ดส่วนแสดง Err01](assets/images/cuh.sdvc311.sms.manual.v7.01/page-0048-vcrop-00.png) |
| Err02 | กระแสเกิน | ลดแรงดันไฟฟ้าขาออกลงอย่างเหมาะสม จากนั้นรีสตาร์ทเอาต์พุต | ![จอแสดงผลเจ็ดส่วนแสดง Err02](assets/images/cuh.sdvc311.sms.manual.v7.01/page-0048-vcrop-01.png) |
| Err03 | ความร้อนเกิน | ติดตั้งตัวควบคุมในสภาพแวดล้อมที่มีการระบายอากาศดี | ![จอแสดงผลเจ็ดส่วนแสดง Err03](assets/images/cuh.sdvc311.sms.manual.v7.01/page-0048-vcrop-02.png) |
| Err04 | แรงดันไฟฟ้าเกินหรือต่ำเกิน | ตรวจสอบว่าแรงดันไฟฟ้าขาเข้าอยู่ระหว่าง AC 85~250Vac | ![จอแสดงผลเจ็ดส่วนแสดง Err04](assets/images/cuh.sdvc311.sms.manual.v7.01/page-0048-vcrop-03.png) |
| Err05 | การสื่อสารภายในผิดปกติ | ตรวจสอบว่าไม่มีแหล่งจ่ายไฟภายนอกเชื่อมต่อกับพอร์ตจ่ายไฟ 24V หรือติดต่อฝ่ายสนับสนุนทางเทคนิคของเรา | ![จอแสดงผลเจ็ดส่วนแสดง Err05](assets/images/cuh.sdvc311.sms.manual.v7.01/page-0048-vcrop-04.png) |
| Err06 | เซ็นเซอร์อุณหภูมิผิดปกติ | ตรวจสอบว่าอุณหภูมิการทำงานไม่ต่ำกว่า -20℃ หรือติดต่อฝ่ายสนับสนุนทางเทคนิคของเรา | ![จอแสดงผลเจ็ดส่วนแสดง Err06](assets/images/cuh.sdvc311.sms.manual.v7.01/page-0048-vcrop-05.png) |
| Err07 | การป้องกันไฟฟ้าลัดวงจรของพอร์ต D | ตรวจสอบว่าโหลดของพอร์ต D ไม่ได้ลัดวงจรและกระแสไม่เกิน 400mA จากนั้นลองรีสตาร์ทเอาต์พุตของพอร์ต D | ![จอแสดงผลเจ็ดส่วนแสดง Err07](assets/images/cuh.sdvc311.sms.manual.v7.01/page-0048-vcrop-06.png) |
| Err10 | เอาต์พุตจ่ายไฟ 24V ผิดปกติ | ตรวจสอบว่าพอร์ต 24V ไม่ได้ลัดวงจรและกระแสไม่เกิน 400mA | ![จอแสดงผลเจ็ดส่วนแสดง Err10](assets/images/cuh.sdvc311.sms.manual.v7.01/page-0048-vcrop-07.png) |
| Err11 | เอาต์พุตจ่ายไฟ 5V ของพอร์ต A ผิดปกติ | ตรวจสอบว่าไฟ 5V ของพอร์ต A ไม่ได้ลัดวงจรหรือไม่ได้เชื่อมต่อกับแหล่งจ่ายแรงดันไฟฟ้าภายนอกที่มากกว่า 5V | ![จอแสดงผลเจ็ดส่วนแสดง Err11](assets/images/cuh.sdvc311.sms.manual.v7.01/page-0048-vcrop-08.png) |
