| 2 | แสดงผลปกติแต่ไม่มีเอาต์พุต | ◆ ตรวจสอบว่าสายไฟอินพุตและสายพลังงานเอาต์พุตเชื่อมต่อแน่นหนา<br>◆ ตรวจสอบว่าค่าพารามิเตอร์แรงดันเอาต์พุตไม่ต่ำเกินไป<br>◆ ตรวจสอบว่าตัวควบคุมไม่ถูกหยุดโดยสัญญาณควบคุม<br>◆ ตรวจสอบว่าตัวควบคุมไม่ถูกหยุดโดยพารามิเตอร์ที่ตั้งเป็นปิดแบบปกติ | |
| 3 | สัญญาณควบคุมไม่ทำงาน | ◆ ตรวจสอบว่าสัญญาณควบคุมถูกป้อนอย่างถูกต้อง<br>◆ ตรวจสอบว่าสายกราวด์ของสัญญาณควบคุมเชื่อมต่อกับตัวควบคุมอย่างถูกต้อง<br>◆ ตรวจสอบว่าความสัมพันธ์ลอจิกของสัญญาณควบคุมตั้งค่าถูกต้องตามที่ท่านต้องการ | |
| 4 | ปรากฏการณ์การเต้นจังหวะชนกัน | ◆ หลีกเลี่ยงการส่งผ่านการสั่นสะเทือนระหว่างตัวสั่นสะเทือนหลายตัว<br>◆ เพิ่มความถี่รีโซแนนซ์ของตัวสั่นสะเทือน | |
| 5 | แสดงผลปกติ ไม่มีเอาต์พุต แต่ได้ยินเสียง | ◆ ปรับพารามิเตอร์ทั้งหมดตามที่คู่มือเล่มนี้แนะนำ | |
