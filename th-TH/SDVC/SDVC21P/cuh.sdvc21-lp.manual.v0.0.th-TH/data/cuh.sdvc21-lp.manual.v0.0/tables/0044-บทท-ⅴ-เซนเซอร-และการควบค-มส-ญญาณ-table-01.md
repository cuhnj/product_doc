| 1 | ไม่มีการแสดงผลหลังเปิดเครื่อง | ➔ตรวจสอบให้แน่ใจว่าเต้าเสียบจ่ายไฟมีไฟฟ้า<br>➔ตรวจสอบให้แน่ใจว่าสายไฟอินพุตเชื่อมต่อกับเต้าเสียบจ่ายไฟอย่างเชื่อถือได้ | |
| 2 | แสดงผลปกติแต่ไม่มีเอาต์พุต | ➔ตรวจสอบให้แน่ใจว่าสายไฟอินพุตและสายไฟเอาต์พุตเชื่อมต่อแน่นหนา<br>➔ตรวจสอบให้แน่ใจว่าค่าพารามิเตอร์แรงดันเอาต์พุตไม่น้อยเกินไป<br>➔ตรวจสอบให้แน่ใจว่าตัวควบคุมไม่ถูกหยุดด้วยสัญญาณควบคุม<br>➔ตรวจสอบให้แน่ใจว่าตัวควบคุมไม่ถูกหยุดด้วยพารามิเตอร์ที่ตั้งค่าเป็นปกติปิด | |
| 3 | สัญญาณควบคุมไม่มีผล | ➔ตรวจสอบให้แน่ใจว่าป้อนสัญญาณควบคุมอย่างถูกต้อง<br>➔ตรวจสอบให้แน่ใจว่าสายกราวด์ของสัญญาณควบคุมเชื่อมต่อกับตัวควบคุมอย่างถูกต้อง<br>➔ตรวจสอบให้แน่ใจว่าความสัมพันธ์เชิงตรรกะของสัญญาณควบคุมถูกตั้งค่าอย่างถูกต้องตามที่คุณต้องการ | |
| 4 | แสดงผลปกติ ไม่มีเอาต์พุต แต่ได้ยินเสียง | ➔ปรับพารามิเตอร์ทั้งหมดตามที่คู่มือนี้แนะนำ | |
| 5 | Err2 | ➔กระแสเอาต์พุตเกิน ตรวจสอบให้แน่ใจว่าข้อกำหนดของเครื่องสั่นไม่เกินขีดจำกัดของตัวควบคุม<br>➔เอาต์พุตลัดวงจร ตรวจสอบให้แน่ใจว่าสายไฟเอาต์พุตและขั้วต่อการบินของสายไฟเอาต์พุตไม่ลัดวงจร<br>➔ตรวจสอบให้แน่ใจว่าสายไฟเอาต์พุตเชื่อมต่ออย่างเชื่อถือได้ระหว่างตัวควบคุมกับเครื่องสั่น<br>➔ตรวจสอบให้แน่ใจว่าตัวควบคุมต่อสายดินอย่างเชื่อถือได้ | ![จอแสดงผล 7 เซ็กเมนต์ Err2](assets/images/cuh.sdvc21-lp.manual.v0.0/page-0042-vcrop-00.png) |
| 6 | Err3 | ➔ความร้อนเกิน โปรดวางตัวควบคุมในสภาพแวดล้อมที่มีการระบายอากาศดี | ![จอแสดงผล 7 เซ็กเมนต์ Err3](assets/images/cuh.sdvc21-lp.manual.v0.0/page-0042-vcrop-01.png) |
