|---|---|---|---|
| ไม่มีการแสดงผลหลังเปิดเครื่อง | | ตรวจสอบว่าเต้ารับไฟมีไฟฟ้า<br>ตรวจสอบว่าสายไฟฟ้าอินพุตต่อกับเต้ารับไฟอย่างมั่นคงหรือไม่ | |
| แสดงผลปกติ แต่ไม่มีเอาต์พุต | | ตรวจสอบว่าสายเอาต์พุตต่อกับตัวสั่นสะเทือนอย่างมั่นคงหรือไม่<br>ตรวจสอบว่าแรงดันเอาต์พุตไม่ต่ำเกินไป<br>ตรวจสอบว่าไฟแสดงสถานะหยุดทำงานไม่ติด<br>โปรดตรวจสอบว่าได้ตั้งค่า Normal Close ของพารามิเตอร์ไว้หรือไม่ ซึ่งทำให้เอาต์พุตของตัวควบคุมหยุด | |
| สัญญาณควบคุมไม่มีผล | | ตรวจสอบว่าสัญญาณควบคุมถูกป้อนอย่างถูกต้องหรือไม่<br>ตรวจสอบว่าสายกราวนด์ของสัญญาณควบคุมต่อเข้าตัวควบคุมอย่างถูกต้องหรือไม่<br>ตรวจสอบว่าความสัมพันธ์ลอจิกของสัญญาณควบคุมถูกตั้งตามที่ต้องการหรือไม่ | |
| ปรากฏการณ์บีต (Beat) | | หลีกเลี่ยงการส่งผ่านการสั่นสะเทือนระหว่างตัวสั่นสะเทือน<br>เพิ่มความถี่ความถี่สั่นพ้องของตัวสั่นสะเทือนให้สูงขึ้น | |
| แสดงผลปกติ ไม่มีเอาต์พุต แต่ได้ยินเสียง | | ปรับพารามิเตอร์ทั้งหมดตามที่คู่มือเล่มนี้แนะนำ | |
