<!-- publish-data-sidecar: section=46 heading='7.3 คำแนะนำการแก้ไขปัญหาและคำอธิบายข้อผิดพลาด' role=generic source_md=doc.md -->

| รหัสข้อผิดพลาด | คำจำกัดความ (ปรากฏการณ์) | วิธีการแก้ไขปัญหา |
|---|---|---|
| Er01A/Er01b | ช่องสัญญาณ A/B ลัดวงจร<br>(ทั้งสองช่องหยุดเอาต์พุต) | ◆ ตรวจสอบให้แน่ใจว่าโหลดไม่ลัดวงจร จากนั้นลองเริ่มเอาต์พุตของตัวควบคุมใหม่โดยกดปุ่มเปิด/ปิดเอาต์พุตสองครั้ง หรือจ่ายไฟให้ตัวควบคุมใหม่ |
| Er02 | ช่อง AB รวมกันกระแสเกิน<br>(ทั้งสองช่องหยุดเอาต์พุตชั่วคราว รีสตาร์ทหลัง 2 วินาที) | ◆ ลดแรงดันเอาต์พุตลงอย่างเหมาะสม จากนั้นรีสตาร์ทเอาต์พุต |
| Er02A/Er02b | ช่องสัญญาณ A/B กระแสเกินแยกกัน<br>(ช่องที่กระแสเกินหยุดเอาต์พุต รีสตาร์ทหลัง 2 วินาที) | |
| Er02A./Er02b. | ช่องสัญญาณ A/B กระแสเกินแยกกันถึงค่าสูงสุดที่ตั้งไว้ | |
| Er03 | ความร้อนเกินหรือความเย็นเกิน<br>(ทั้งสองช่องหยุดเอาต์พุต กู้คืนอัตโนมัติที่ -20℃~60℃) | ◆ ติดตั้งตัวควบคุมในสภาพแวดล้อมที่มีการระบายอากาศดี หรือหลีกเลี่ยงความเย็นจัด |
| Er041/Er042 | แรงดันจ่ายไฟต่ำ/เกิน<br>(ทั้งสองช่องหยุดเอาต์พุต กู้คืนอัตโนมัติ) | ◆ ตรวจสอบให้แน่ใจว่าแรงดันอินพุตอยู่ระหว่าง AC 85~250Vac |
| Er05 | การสื่อสารภายในผิดปกติ<br>(ทั้งสองช่องหยุดเอาต์พุต) | ◆ ตรวจสอบให้แน่ใจว่าไม่มีแหล่งจ่ายไฟภายนอกเชื่อมต่อกับพอร์ตไฟ 24V หรือติดต่อฝ่ายสนับสนุนทางเทคนิคของเรา |
| Er06 | เซ็นเซอร์อุณหภูมิผิดปกติ<br>(ทั้งสองช่องหยุดเอาต์พุต) | ◆ ตรวจสอบให้แน่ใจว่าอุณหภูมิการทำงานไม่ต่ำกว่า -20℃ หรือติดต่อฝ่ายสนับสนุนทางเทคนิคของเรา |
| Er07A/Er07b | ช่องสัญญาณ A/B พอร์ต D ลัดวงจร<br>(เอาต์พุตควบคุมช่องสัญญาณ A/B หยุด ลองรีสตาร์ทหลัง 2 วินาที) | ◆ ตรวจสอบให้แน่ใจว่าโหลดของพอร์ต D ไม่ลัดวงจรและกระแสไม่เกิน 350mA |
| Er10 | เอาต์พุตไฟ 24V ผิดปกติ<br>(ปิดเอาต์พุต 24V ลองรีสตาร์ทหลัง 2 วินาที) | ◆ ตรวจสอบให้แน่ใจว่าพอร์ต 24V ไม่ลัดวงจรและกระแสไม่เกิน 700mA |
| Er11 | เอาต์พุตไฟ 5V ผิดปกติ<br>(ฟังก์ชันควบคุมความเร็วถูกปิดชั่วคราว และกู้คืนเมื่อรีสตาร์ทอัตโนมัติ) | ◆ ตรวจสอบให้แน่ใจว่าไฟ 5V ของพอร์ต A ไม่ลัดวงจรหรือไม่ได้เชื่อมต่อกับแรงดันไฟภายนอกที่เกิน 5V |
| Er12 | แรงดันจ่ายไฟ 24V ผิดปกติ<br>(ทั้งสองช่องหยุดเอาต์พุต เอาต์พุตควบคุมมีความต้านทานสูง กู้คืนอัตโนมัติ) | ◆ ตรวจสอบให้แน่ใจว่าไม่มีแหล่งจ่ายไฟภายนอกเชื่อมต่อกับพอร์ตไฟ 24V |
