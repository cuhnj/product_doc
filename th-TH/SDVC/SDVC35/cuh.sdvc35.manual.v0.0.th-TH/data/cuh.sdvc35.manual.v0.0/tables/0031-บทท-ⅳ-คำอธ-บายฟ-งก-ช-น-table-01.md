| ประเภทสัญญาณควบคุมระยะไกล | สัญญาณควบคุมระยะไกล | แรงดันเอาต์พุต/ความเร็วป้อน |
|---|---|---|
| Panel | | แรงดันเอาต์พุตและความเร็วป้อนไม่ถูกควบคุมโดยสัญญาณควบคุมระยะไกล |
| 20mA | <2mA | เมื่อโหมดแรงดันไฟฟ้าเป็น Manual แรงดันเอาต์พุต = 0<br>เมื่อโหมดแรงดันไฟฟ้าเป็น Auto ความเร็วป้อน = 0<br>LCD แสดงข้อมูลข้อผิดพลาด "<2mA Err" |
| | 2mA~4 mA | แรงดันเอาต์พุต = 0, ความเร็วป้อน = 0 |
| | 4 mA ~20mA | ควบคุมแบบสัดส่วนโดยสัญญาณควบคุมระยะไกล (0%~100%)<br>เมื่อโหมดแรงดันไฟฟ้าเป็น Manual แรงดันเอาต์พุต = (กระแสอินพุต - 4mA)/16 ×แรงดันเอาต์พุตสูงสุด<br>เมื่อโหมดแรงดันไฟฟ้าเป็น Auto ความเร็วป้อน = (กระแสอินพุต - 4mA)/16 ×ความเร็วป้อนสูงสุด |
| 1~5V | <0.5V | แรงดันเอาต์พุต = 0, ความเร็วป้อน = 0<br>LCD แสดงข้อมูลข้อผิดพลาด "<0.5V Err" |
| | 0.5V~1V | แรงดันเอาต์พุต = 0, ความเร็วป้อน = 0 |
| | 1V~5V | ควบคุมแบบสัดส่วนโดยสัญญาณควบคุมระยะไกล (0%~100%)<br>เมื่อโหมดแรงดันไฟฟ้าเป็น Manual แรงดันเอาต์พุต = (แรงดันอินพุต 1V)/4 ×แรงดันเอาต์พุตสูงสุด<br>เมื่อโหมดแรงดันไฟฟ้าเป็น Manual แรงดันเอาต์พุต = (แรงดันอินพุต 1V)/4 ×แรงดันเอาต์พุตสูงสุด |
| 0~5V | 0V~5V | ควบคุมแบบสัดส่วนโดยสัญญาณควบคุมระยะไกล (0%~100%)<br>เมื่อโหมดแรงดันไฟฟ้าเป็น Manual แรงดันเอาต์พุต = แรงดันอินพุต/5 × แรงดันเอาต์พุตสูงสุด<br>เมื่อโหมดแรงดันไฟฟ้าเป็น Auto ความเร็วป้อน = แรงดันอินพุต/5 ×ความเร็วป้อนสูงสุด |
| 0~10V | 0V~10V | ควบคุมแบบสัดส่วนโดยสัญญาณควบคุมระยะไกล (0%~100%)<br>เมื่อโหมดแรงดันไฟฟ้าเป็น Manual แรงดันเอาต์พุต = แรงดันอินพุต/10 × แรงดันเอาต์พุตสูงสุด<br>เมื่อโหมดแรงดันไฟฟ้าเป็น Auto ความเร็วป้อน = แรงดันอินพุต/10 ×ความเร็วป้อนสูงสุด |
| Meter (โพเทนชิออมิเตอร์) | อัตราการแบ่งแรงดันของโพเทนชิออมิเตอร์ <4% | แรงดันเอาต์พุต = 0, ความเร็วป้อน = 0 |
| | อัตราการแบ่งแรงดันของโพเทนชิออมิเตอร์เป็น 4%~96% | ควบคุมแบบสัดส่วนโดยสัญญาณควบคุมระยะไกล (0%~100%)<br>เมื่อโหมดแรงดันไฟฟ้าเป็น Manual แรงดันเอาต์พุต = ((อัตราการแบ่งแรงดัน - 4%)/92%)× แรงดันเอาต์พุตสูงสุด<br>เมื่อโหมดแรงดันไฟฟ้าเป็น Auto ความเร็วป้อน =((แรงดันอินพุต แรงดันภายใน × 4%)/แรงดันภายใน × 92%) ×ความเร็วป้อนสูงสุด |
