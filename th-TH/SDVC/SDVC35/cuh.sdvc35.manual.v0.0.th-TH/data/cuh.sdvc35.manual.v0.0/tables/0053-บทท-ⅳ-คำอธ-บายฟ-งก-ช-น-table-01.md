| | อาการข้อผิดพลาด | ข้อเสนอแนะการแก้ไขปัญหา |
|---|---|---|
| 1 | ไม่แสดงผลหลังจากเปิดเครื่อง | • ตรวจสอบให้แน่ใจว่าปลั๊กไฟมีกระแสไฟฟ้า<br>• ตรวจสอบให้แน่ใจว่าสายไฟกำลังอินพุตเชื่อมต่อกับปลั๊กไฟอย่างน่าเชื่อถือ |
| 2 | แสดงผลปกติ แต่ไม่มีเอาต์พุต | • ตรวจสอบให้แน่ใจว่าแรงดันเอาต์พุตไม่เล็กเกินไป<br>• ตรวจสอบให้แน่ใจว่าสถานะการทำงานของตัวควบคุมไม่ใช่ “Man” ที่ควบคุมโดยการกดปุ่ม “ON/OFF” บนแผงควบคุม<br>• ตรวจสอบให้แน่ใจว่าสถานะการทำงานของตัวควบคุมไม่ใช่ “STP” ที่ควบคุมโดยพอร์ต C/E<br>• ตรวจสอบให้แน่ใจว่าสถานะการทำงานของตัวควบคุมไม่ใช่ “STP” ที่ควบคุมโดยพารามิเตอร์ทิศทางตรรกะของพอร์ต C/E<br>• รีเซ็ตตัวควบคุมโดยการคืนค่าการตั้งค่าเริ่มต้นซึ่งปรับในกลุ่มฟังก์ชัน 8 |
| 3 | พอร์ต C/E ไม่สามารถทำงานได้ตามปกติ | • ตรวจสอบให้แน่ใจว่าสายสัญญาณควบคุมเปิด/ปิดเชื่อมต่อกับพอร์ต C/E อย่างถูกต้อง<br>• ตรวจสอบให้แน่ใจว่าพารามิเตอร์ทั้งหมดของพอร์ต C/E ที่คุณปรับนั้นถูกต้อง<br>• รีเซ็ตตัวควบคุมโดยการคืนค่าการตั้งค่าเริ่มต้นซึ่งปรับในกลุ่มฟังก์ชัน 8 |
| 4 | ปรากฏการณ์บีต | • เชื่อมต่อสายสัญญาณซิงค์ระหว่างตัวควบคุมและตั้งค่าตัวควบคุมทาสเป็นโหมดซิงค์ |
| 5 | แสดงผลปกติ ได้ยินเสียงจากเครื่องป้อนวัสดุแบบสั่นสะเทือนแต่ไม่มีเอาต์พุต | • ตรวจสอบให้แน่ใจว่าความถี่เอาต์พุตไม่ห่างจากความถี่เรโซแนนซ์ของเครื่องป้อนวัสดุแบบสั่นสะเทือนมากนัก<br>• รีเซ็ตตัวควบคุมโดยการคืนค่าการตั้งค่าเริ่มต้นซึ่งปรับในกลุ่มฟังก์ชัน 8 |
