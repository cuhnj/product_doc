<!-- publish-data-sidecar: section=28 heading='5.4.2 제어 출력 신호원 및 논리 다이어그램' role=generic source_md=doc.md -->

| 신호원 | 의미 |
|---|---|
| 0 | 무효 신호 |
| 1 | 유효 신호 |
| b | 지능형 광전 감지 포트 신호 |
| -b | 지능형 광전 감지 포트 신호 반전 |
| C | 스위치 센서 포트 신호 |
| -C | 스위치 센서 포트 신호 반전 |
| od | 제어 출력 포트 신호 |
| -od | 제어 출력 포트 신호 반전 |
| oq | 메인 전원 출력 포트 신호 |
| -oq | 메인 전원 출력 포트 신호 반전 |
