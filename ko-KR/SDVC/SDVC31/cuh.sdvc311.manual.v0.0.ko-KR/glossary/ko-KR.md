## 4. 번역 관례 결정

- **컨트롤러**를 "the controller"의 일관된 용어로 사용; 전체 제품명은 "진동 피더용 가변 주파수 디지털 컨트롤러" (본 설명서의 제목과 일치).
- **진동 피더**를 "vibratory feeder"의 한국어 판으로 사용.
- **ON/OFF**는 영문 그대로 사용; 시작/정지 버튼은 **ON/OFF 버튼**으로 표기.
- **소프트 시작**을 "Soft Startup"으로 사용; **소프트 시작 시간**은 "Soft Startup Time".
- **원거리 속도 제어**를 "Remote Speed Control"으로 사용; 해당 연결 방식(포텐셔미터, 1~5V, 4~20mA)은 원본을 따름.
- 단자 명칭(A1~A3, B1~B4, C1~C3, D1~D2, I1~I2) 및 표준 약어(RGND, GND, RX, TX)는 장비 명칭으로서 그대로 유지; 단자의 기능 설명은 번역됨(입력, 출력, 5V 출력, 24V 출력).
- 파라미터 기호(U, E, J, L, t, L-, J-, F1~F4, n, H, y, r, P, FA, C, e, 8.8.8.8.8., Pin) 및 열거 값(nPn, PnP, ut0, ut1; And, or, Xor)은 장비 표시 텍스트 및 설정 값이므로 변경하지 않음.
- 숫자 및 단위 형식은 영어 원본과 동일하게 유지 (예: 0.0~20.0 s; 40.0~400.0 Hz; 0~260 V; 85~250 VAC); 범위는 틸드 "~"로 표기.
- 안전 표시는 원본을 따름: **⚠ 위험 / ⚠ 경고 / ⚠ 주의 / Notice / ❗ 필수**.
- 에러 코드(Err01 … Err11)는 변경하지 않음.
- 이미지: 모든 이미지 참조는 영어 원본과 동일한 이미지를 사용 (`assets/images/cuh.sdvc.manual.v0.0/`); 한국어 판은 영어 원본 이미지를 사용합니다.
